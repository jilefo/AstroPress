# AstroPress 用户操作手册

> 面向站长的完整操作指南，涵盖后台所有模块的使用方法。

---

## 一、登录与仪表盘

### 1.1 登录后台

1. 访问 `https://your-site.workers.dev/login`
2. 输入管理员账号密码
3. 可选：开启「记住我」（30 天会话）

### 1.2 仪表盘概览

登录后进入 `/admin/dashboard`，可查看：

| 模块 | 说明 |
|---|---|
| 文章统计 | 已发布/草稿/页面数量 |
| 评论统计 | 待审核/已批准数量 |
| 媒体库 | 文件总数与占用空间 |
| 缓存状态 | 页面缓存命中率（见「仪表盘缓存状态卡」） |
| 最近活动 | 登录/编辑/评论等操作日志 |

### 1.3 侧栏导航（可折叠分组）

- **内容**：文章、页面、自定义文章类型、媒体库、评论、表单、广告管理
- **结构**：菜单、分类、标签
- **Site**：网站目录、重定向、通知中心
- **Appearance**：主题、主题编辑器、自定义 CSS
- **插件套件**（9 个折叠组）：
  - 安全与防护：登录锁定、2FA、维护模式、安全头
  - 缓存与性能：页面缓存、懒加载、HTML 优化、缓存预热
  - SEO 与流量：SEO 工具、站点地图、统计分析
  - 内容与互动：评论、点赞、相关文章、阅读模式
  - 营销与增长：广告、弹窗、追踪像素
  - 工具与集成：文件管理、数据库控制台、备份、Git 同步
  - AI 与自动化：AI 写作助手、AI 一键填写、Webhook 发布
  - 多语言与国际化：多语言、翻译管理
  - 开发者工具：自定义字段、自定义文章类型、短代码

> **提示**：被禁用的插件其菜单链接自动隐藏；点击分组标题可展开/收起，状态持久化到 localStorage。

## 二、内容管理

### 2.1 发布文章

1. 「内容 → 文章 → 写文章」
2. 填写标题、内容（支持 Markdown / 区块编辑器）
3. 右侧边栏设置：
   - **分类**：选择一个或多个
   - **标签**：逗号分隔
   - **特色图片**：从媒体库选择或上传
   - **摘要**：留空则自动截取前 200 字
   - **SEO**：自定义标题/描述/关键词（可选，留空自动生成）
4. 点击「发布」或「保存草稿」

### 2.2 使用 AI 写作助手

1. 编辑器右上角点击「AI 写作」
2. 选择模式：
   - **深度长文**：根据标题生成 2000+ 字深度文章
   - **公众号爆款**：生成带 emoji 和悬念的公众号风格文章
   - **内容扩充**：选中一段文字，AI 扩充至 500 字
3. 生成后自动插入编辑器，可二次编辑

> **注意**：AI 生成内容建议人工复核，避免事实性错误。

### 2.3 上传与管理媒体

1. 「内容 → 媒体库 → 上传」
2. 支持拖拽上传，单文件最大 100MB（可通过 `AP_AV_MAX_MB` 调整）
3. 图片自动生成缩略图，支持裁剪/旋转
4. 创建文件夹分类管理（如「2026 封面」「产品截图」）

### 2.4 管理评论

1. 「内容 → 评论」
2. 待审核评论高亮显示，点击「批准」或「垃圾评论」
3. 已批准评论可「回复」（管理员回复会显示「站长」标识）
4. 蜜罐机制：自动拦截机器人（访客无感知）

## 三、外观与主题

### 3.1 切换主题

1. 「外观 → 主题」
2. 点击主题卡片上的「激活」
3. 前台立即生效（无需重新部署）

### 3.2 自定义主题

1. 「外观 → 主题编辑器」
2. 可视化编辑页头/页脚/侧边栏
3. 支持拖拽区块、修改颜色/字体
4. 保存后实时预览

### 3.3 导入新主题

1. 下载主题包（.zip）
2. 「外观 → 主题 → 导入」
3. 选择 zip 文件，勾选「创建示例页面」
4. 导入后可在列表中激活

## 四、插件管理

### 4.1 启用/禁用插件

1. 「插件 → 已安装插件」
2. 点击插件卡片上的「启用」或「禁用」
3. **套件级联**：禁用「缓存套件」会同时禁用其成员插件（页面缓存/懒加载/HTML 优化等）

### 4.2 配置插件

启用后，插件卡片上会出现「设置」按钮，点击进入配置页。

### 4.3 常用插件配置示例

**页面缓存**：
- 「插件 → 缓存套件 → 页面缓存」
- 开启后，已发布的文章页会被缓存（默认 TTL 1 小时）
- 可配置排除规则（如 `/search` 不缓存）

**网站目录**：
- 「Site → 网站目录」
- 添加分类 → 添加链接（标题、URL、描述、图标）
- 支持点击统计，前台 `/directory` 展示

**重定向**：
- 「Site → 重定向」
- 添加规则：旧路径 → 新路径（301 永久重定向）
- 支持正则表达式（如 `/old-blog/(.*)` → `/blog/$1`）

## 五、SEO 优化

### 5.1 全局 SEO 设置

1. 「设置 → SEO」
2. 填写站点标题、副标题、默认描述
3. 配置社交媒体默认图片（用于 og:image）

### 5.2 单篇文章 SEO

编辑文章时，右侧边栏「SEO」面板：
- **SEO 标题**：留空则使用文章标题
- **Meta 描述**：留空则自动截取摘要
- **Focus Keyword**：主要关键词（用于内链推荐）
- **Canonical URL**：防止重复内容

### 5.3 站点地图

自动生成，访问 `/sitemap.xml` 验证。

提交到搜索引擎：
- Google Search Console
- 百度站长平台

## 六、多语言（可选）

### 6.1 启用多语言

1. 「插件 → 多语言套件 → 多语言」
2. 添加语言（如 English、日本語）
3. 设置默认语言

### 6.2 翻译内容

1. 编辑文章时，右侧边栏「语言」面板
2. 点击「添加翻译」创建对应语言版本
3. 前台自动显示语言切换器

---

## 七、安全建议

### 7.1 强制开启 2FA（两步验证）

1. 「用户 → 个人资料」
2. 开启「两步验证」，扫描二维码绑定
3. 下次登录需输入 6 位验证码

### 7.2 定期备份

1. 「插件 → 工具套件 → 备份」
2. 配置自动备份（每日/每周）
3. 备份文件存储在 R2，可下载到本地

### 7.3 创建第二管理员

防止单管理员账号被锁：
1. 「用户 → 添加用户」
2. 角色选择「管理员」
3. 使用独立邮箱和强密码

## 八、性能优化

### 8.1 开启页面缓存

「插件 → 缓存套件 → 页面缓存」→ 启用

效果：已发布页面直接返回缓存，响应时间从 1.5s 降至 50ms。

### 8.2 开启图片懒加载

「插件 → 缓存套件 → 懒加载」→ 启用

效果：图片进入视口才加载，减少首屏流量。

### 8.3 配置缓存预热

「插件 → 缓存套件 → 缓存预热」→ 添加 URL 列表

效果：定时主动访问页面，提前生成缓存。

## 九、故障排查

### 9.1 健康检查

访问 `/ap-health` 查看系统状态：

```json
{
  "ok": true,
  "checks": {
    "database": "ok",
    "storage": "ok",
    "ai": "ok",
    "setupComplete": true
  }
}
```

任何一项非 `ok` 都会导致 `ok: false`。

### 9.2 查看活动日志

「Site → 活动日志」可查看：
- 登录成功/失败记录
- 文章编辑记录
- 插件启停记录

### 9.3 404 监控

「插件 → SEO 套件 → 404 监控」可查看访客访问的无效链接，便于设置重定向。

## 十、进阶技巧

### 10.1 使用 Webhook 自动发布

1. 「插件 → AI 与自动化 → Webhook 发布」
2. 创建 Webhook Key
3. 外部系统 POST 到 `/ap-webhook/publish` 即可自动发布文章

详见 [docs/API.md](./API.md)。

### 10.2 使用自定义字段

1. 「开发者工具 → 自定义字段」
2. 创建字段组（如「书籍信息」：作者、出版社、ISBN）
3. 绑定到文章类型
4. 编辑文章时自动显示自定义字段面板

### 10.3 使用短代码

在文章内容中插入：

```
[ads slot="in-content"]
[related-posts count="5"]
[donation]
```

前台自动渲染为对应组件。
