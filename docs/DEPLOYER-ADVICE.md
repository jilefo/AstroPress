# 部署者建议书

> 面向即将部署 AstroPress 的运维/站长，按重要度排序的生产环境建议。

---

## 一、安全基线（必做）

1. **安装后立即创建第二管理员账号**——单管理员被锁 = 全站失管（HIGH 风险）
2. **所有管理员开启 2FA**——「用户 → 个人资料 → 两步验证」
3. **强密码策略**——至少 12 位，混合大小写+数字+符号；系统已内置登录失败 10 次锁定 15 分钟
4. **AUTH_SECRET 使用 32 位以上随机串**——`openssl rand -base64 32` 生成；泄露后所有会话立即失效，需全员重登
5. **后台路径保护**（可选）——Cloudflare Dashboard 配置 IP Access Rules，仅允许可信 IP 访问 `/admin` 与 `/login`

## 二、部署配置（强烈建议）

6. **绑定自定义域名**——`workers.dev` 域下 cache-warmer 自预热会被 CF 平台拦截；绑定自定义域名后全部功能正常
7. **确认三类绑定就绪**——部署后访问 `/ap-health`，确保 `database/storage/ai` 全部 `ok`
8. **首次部署后必须激活主题**——setup 向导不写 `astropress_active_theme`，不激活主题首页 404
9. **配置 AI 服务商**——「设置 → AI」选 Cloudflare AI（免费、零配置）或自定义 OpenAI 兼容端点（DeepSeek 等国内平台）
10. **开启页面缓存 + 懒加载**——「插件 → 缓存套件」，响应时间从 ~1.5s 降至 ~50ms

## 三、运维保障（建议）

11. **配置健康监控**——UptimeRobot 监控 `/ap-health`，关键词 `ok:true`，5 分钟间隔
12. **开启自动备份**——「插件 → 工具套件 → 备份」，每日备份到 R2
13. **定期查看 404 监控**——「插件 → SEO 套件 → 404 监控」，为高频 404 路径设置重定向
14. **关注活动日志**——「Site → 活动日志」，异常登录/批量删除一目了然
15. **更新前先备份**——升级版本前导出数据库 + 下载媒体备份

## 四、性能调优（可选）

16. **配置缓存预热**——「缓存预热」添加首页 + Top 10 文章，消除冷启动
17. **图片使用 WebP**——体积比 JPG 小 30%，后台上传自动优化
18. **合理使用「加载更多」**——长列表页用无限滚动替代分页，减少整页刷新

## 五、适用规模说明（诚实边界）

| 指标 | 舒适区 | 极限区 |
|---|---|---|
| 日 UV | < 10,000 | 50,000（需开启全部缓存） |
| 文章数 | < 5,000 | 20,000 |
| 并发评论 | < 10/分钟 | 平台限流兜底 |
| 媒体存储 | < 10GB（免费额度） | 按量付费 |

超出舒适区请考虑 Node.js 自托管 + PostgreSQL 方案（见 [DEPLOY-NODE.md](./DEPLOY-NODE.md)）。

## 六、内容合规提示

- AI 生成内容建议人工复核后发布（事实性/版权风险自负）
- 评论蜜罐+频控已内置，仍建议保持「人工审核」开启
- 广告内容需符合投放地区法律法规
